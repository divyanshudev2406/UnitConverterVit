# Project Statement

## Project Title

Unit Converter: A Command-Line Application in Python

## Problem Statement

Changing a value from one unit to another by hand takes time and it is easy to make mistakes, especially with formulas like Celsius to Fahrenheit. This project builds a simple command-line program that does these conversions for the user. The user picks a category and a conversion from a menu, enters a number, and gets the answer.

## Objectives

- Build a working unit converter that runs in the terminal.
- Support length conversions (meter and kilometer) and temperature conversions (Celsius and Fahrenheit).
- Use menus so the program is easy to follow.
- Handle wrong menu choices by showing the menu again.
- Use only basic Python, with no external libraries.

## Scope

**Included**

- Meter to Kilometer
- Kilometer to Meter
- Celsius to Fahrenheit
- Fahrenheit to Celsius

**Not included**

- Other units such as miles, feet, weight, or Kelvin
- Graphical interface
- Repeated conversions in a single run
- Handling of non-numeric input for values

## Target Users

Students and beginners who want a quick way to convert common units, and anyone learning basic Python who wants to see how functions and menus work together.

## Technology

- Language: Python 3
- Interface: Command line (terminal)
- Libraries: None

## Expected Outcome

A program that runs from the terminal, shows clear menus, and prints the correct converted value for the chosen conversion.
